# Third-party software

The web wallet uses MIT-licensed `@noble/curves`, `@noble/hashes`, `@scure/base`, `@scure/bip32`, `@scure/bip39`, and `esbuild`. Exact versions and integrity hashes are in `wallet-web/package-lock.json`.

The Android shell uses AndroidX WorkManager, OkHttp, Google Code Scanner, and Google ML Kit barcode scanning. Their licenses and notices remain governed by their upstream distributions. Dependency coordinates and versions are declared in `app/build.gradle`.
